# ⚡ ArcTrace

> **Proof of Work & Social Engagement Engine for Arc Network** (Circle's Layer-1 Stablecoin Blockchain).

ArcTrace tracks, quantifies, and verifies community contributions, impressions, and viral discussions across X (Twitter) for **Arc Network**.

![ArcTrace Preview](https://raw.githubusercontent.com/yournahian/ArcTrace-/main/preview.png)

---

## 🌟 Key Features

- **⚡ Arc Proof of Work**: Calculate real impressions generated by any user contributing to Arc Network across a continuous cumulative curve.
- **🏆 Best Post Spotlight**: Automatically highlights the user's #1 highest-impact Arc post with real views, likes, replies, and links to X.
- **🌟 Best Posts About Arc**: A searchable catalog of ranked Arc tweets by impressions.
- **💎 Arc Gems**: Leaderboard spotlighting core researchers, builders, and ecosystem leaders with standard follower/following stats.
- **🖼️ Canvas Badge Export**: Download a 2x retina PNG Proof-of-Work badge directly for sharing on X.
- **🎨 Arc Protocol Aesthetic**: Built with the institutional design system of [arc.io](https://www.arc.io) (Deep Protocol Navy, Space Grotesk, DM Sans, ambient glow).

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, React 18)
- **Language**: TypeScript
- **Styling**: Vanilla CSS with Arc Design System tokens
- **Graphics**: HTML5 Canvas 2D API for high-resolution PNG generation

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/yournahian/ArcTrace-.git
cd ArcTrace-
npm install
```

### 2. Environment Variables (Optional)
Create `.env.local` if you wish to attach an official X API v2 Bearer Token:
```env
X_API_BEARER_TOKEN=your_token_here
```
*Note: If omitted, ArcTrace automatically uses the built-in live Arc indexing engine.*

### 3. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Production Build
```bash
npm run build
npm start
```
